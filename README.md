# Draw-Fate

for my nephew Amar Capaldi

## 기능

- **1개 뽑기**: 마작패 1개를 랜덤으로 뽑습니다
- **13개 뽑기 / 나머지 전부 뽑기**: 한 번에 13개 전부, 또는 뽑다가 나머지를 전부 뽑습니다
- **뽑기 중단**: 13개를 다 뽑기 전에 중단하고 저장할 수 있습니다
- **운명 기록**: 뽑은 마작패의 기록을 확인할 수 있습니다. 앱 삭제 시 기록이 전부 삭제 되므로 주의 요망.
- **기록 삭제**: 기록 목록에서 항목을 왼쪽으로 스와이프하면 삭제됩니다

## 마작패 구성 (139장)

| 종류 | 패 | 장수 |
|------|-----|------|
| 만수패 (萬) | 1만 ~ 9만 (적도라 1장) | 36장 |
| 통수패 (筒) | 1통 ~ 9통 (적도라 1장) | 36장 |
| 삭수패 (索) | 1삭 ~ 9삭 (적도라 1장) | 36장 |
| 풍패 (風) | 동, 남, 서, 북 (각 4장) | 16장 |
| 삼원패 (三元) | 백, 발, 중 (각 4장) | 12장 |
